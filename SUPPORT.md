# Support

## Usage Questions

Check the [README](README.md), especially the safety, build, and profile sections. If the answer is not there, open a GitHub Discussion when enabled or a regular issue with the `question` label.

## Bugs And Features

- Use the bug report form for reproducible defects.
- Use the feature request form for scoped product ideas.
- Search existing issues first and add context to an existing thread when possible.

FocusMode is maintained by volunteers. Response times are not guaranteed.

## Security

Never report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).
